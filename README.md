# Borelang - Interpreted language written in rust
> NOTE: Still in very early development, this might change alot.


## Design Goals
* Rust-like syntax with high-level, python-like expressiveness

## Current Features
* Constant and Mutible Variables
* If and For Statements
* Lightweight built-ins library (not fully)
* Basic error handler

## Code Example
```
# prints "Hello, world!"
greet("world")

fn greet(who) {
  println("Hello, ", world, "!")
}
```
